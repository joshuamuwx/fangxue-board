# 放学公告牌 · School Dismissal Board

学校放学时，家长在校门口挤着问保安"几班放了？"——这个小工具就是解决这件事的：保安每放一个班，在手机上点一下对应班级按钮（可同时放两个班），家长在手机上就能实时看到自己孩子的班级放没放，不用再围着门口问。

- **家长端**：扫码打开网页，选一次"自己班级"，15 秒自动刷新；还差 2 个班时提示"准备出发"，轮到时响铃+震动提醒
- **保安端**：两列大按钮，点一下变绿=已放学（再点可取消），6 位 PIN 码进入，支持多台设备同时使用
- **双通道并行**：看板只是多一个渠道，学校原来的门口翻牌照旧；页面上写明"信息仅供参考，以门口翻牌为准"
- **零成本**：跑在 Cloudflare 免费额度内（Workers + KV），约 560 名家长规模经测算仍在免费线内
- **不存学生信息**：服务器只保存"日期、班级、是否已放、时间"，没有任何学生姓名、电话

本项目最初是一位家长给孩子学校做的公益小工具，现开源出来，希望能帮到更多学校。

## 快速部署（约 20 分钟，全程免费）

代码是一个单文件 Cloudflare Worker（`worker.js`），带本地测试（`node test.mjs`，需 Node 18+）。部署分三步：

### 第一步：改配置（2 分钟）

打开 `worker.js`，只改顶部 `CONFIG` 配置区和 `DEFAULT_ORDER` 班级名单：

- `schoolName`：学校名称（显示在页面标题和页眉）
- `campusName`：校区/校门名称，如"东门"
- `feedbackEmail`：家长"提供建议"按钮的收件邮箱；留空则不显示该按钮
- `logo`：校徽图片地址（图片 URL 或 `data:` 形式）；留空则不显示校徽
- `DEFAULT_ORDER`：放学班级名单（一行一个班的顺序，保安端每天开始前也可临时调整）

### 第二步：Cloudflare 建 KV 并部署（10 分钟）

1. 注册/登录 [cloudflare.com](https://cloudflare.com)（免费计划即可）
2. 左侧 Workers & Pages → KV → Create a namespace，名字如 `fangxue-kv`，把生成的 **ID** 填进 `wrangler.toml` 的 `id = "..."` 处
3. Workers & Pages → Create → Create Worker → 取名（如 `fangxue-board`）→ Deploy
4. 点 Edit code，把 `worker.js` 全部内容粘贴进去 → Save and deploy
5. Settings → Bindings → Add → KV namespace → 变量名填 `KV`，选第 2 步建的 namespace
6. Settings → Variables → Add Secret：名字 `ADMIN_PIN`，值设 6 位数字（保安进管理端的密码，自己记好，**不要写进代码**）
7. 此时 `https://你的项目名.workers.dev/` 是家长端，`/admin` 是保安端

### 第三步：绑定自己的域名（强烈建议，5 分钟）

`workers.dev` 域名在国内部分网络环境下解析不稳定，正式使用请绑定自己的域名（无需备案，走 Cloudflare 边缘节点）：

1. 把你的域名添加到 Cloudflare（按提示改 NS 到 Cloudflare 给的两个地址）
2. Workers → 你的 Worker → Settings → Domains → Add Custom Domain，如 `fx.example.com`
3. 给家长的二维码、给保安的收藏链接都用这个域名

### 日常使用

- **每天放学前**：保安打开 `/admin` → 输 6 位密码 → 确认顺序点"开始放学"
- **放学中**：哪个班放学点哪个班的按钮（变绿=已放学）；一次放 2 个班就连点两个；点错再点一次取消；然后照着变绿的按钮翻对应牌子
- **放学结束**：点"今日放学结束"
- PIN 连续输错 10 次会锁定来源 IP 10 分钟，防猜密码
- **家长**：门口贴二维码 → 扫码进首页 → 选"自己班级" → 等提醒即可

### 免费额度够不够

- 保安一天点几十次（写 KV，免费 1000 次/天）
- 家长端 15 秒轮询 + 10 秒边缘缓存：约 560 名家长、40 分钟放学高峰，约 2~4 万次读/天（免费 10 万次/天）
- 万一超线：接口会自动降级提示"以门口翻牌为准"，不会崩，双通道设计保证翻牌永远是最终依据

## 文件说明

- `worker.js`：全部代码（家长端+保安端页面+接口），单文件
- `wrangler.toml`：部署配置（本地只用它填 KV 的 ID；也可以用命令行 `wrangler deploy` 部署）
- `test.mjs`：本地测试（`node test.mjs`）
